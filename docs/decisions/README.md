# Decisiones

Una decisión por archivo, numeradas: `0001-titulo.md`. Cada una tiene tres partes:

1. **Contexto:** qué problema había.
2. **Opciones consideradas:** qué alternativas había y por qué no se eligieron.
3. **Decisión:** qué se eligió y qué consecuencias tiene.

Las decisiones cortas basta con anotarlas en [docs/architecture.md](../../docs/architecture.md).
